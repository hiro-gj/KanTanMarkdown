# 非機能要件一覧

| id | category | requirement | targetValue | priority |
| --- | --- | --- | --- | --- |
| NFR-001 | 性能 | シングルHTMLの起動・初期ロード性能 | 一般的なWebブラウザでファイルを開いてから1秒以内に初期表示およびエディタの操作可能状態が完了すること | 高 |
| NFR-002 | 性能 | リアルタイムパース・レンダリング処理性能 | テキスト編集時、Markdownパース、コードハイライト、GitHubアラート変換、ダイアグラム描画を含めて300ms以内にプレビュー更新されること | 高 |
| NFR-003 | 可用性 | スタンドアロン・オフライン動作保証 | 外部サーバーへの通信なしで、編集・プレビュー・画像添付・お絵描き・データ保存の機能が100%正常に動作すること | 高 |
| NFR-004 | 可用性 | 非対応ブラウザ環境での安全なフォールバック処理 | Blob利用不可等の制限環境下において、システムクラッシュを起こさずに閲覧専用モードへ100%安全に遷移し、警告を表示すること | 中 |
| NFR-005 | セキュリティ | ローカルデータ処理による情報漏洩防止 | ドキュメント内容および添付ファイル（Base64等）が外部ネットワークへ送信されないクライアント完結構造を維持すること | 高 |
| NFR-006 | 運用 | マルチエディションの自動ビルド・パッケージング運用 | Gruntビルドコマンドにより、Dev/Lite/Std/Fullなどの指定エディションの単一HTMLファイルおよび更新JSがエラーなく生成されること | 中 |
| NFR-007 | 移行 | バージョンアップ時のデータ・データ構造引継ぎ完全性 | アプリ更新時に、既存ドキュメント、CSS設定、添付画像データ、レイヤー・トリミング情報が失われずに100%保持・更新されること | 高 |
| NFR-008 | 拡張性 | プラグイン・描画モジュールの追加容易性 | 新しい構文パース機能や描画ライブラリを既存のビルドパイプライン（Gruntfile）およびスクリプト構成へ容易に追加・差し替えできること | 中 |
