# バックエンド処理

| id | processName | description | input | output | relatedApi |
| --- | --- | --- | --- | --- | --- |
| BP-001 |  | マークダウンエディタ画面でのキー入力イベントを検知し、Tabキーによるインデント挿入やタブ展開、Shift+Tabキーによる複数行のアウトデント処理、およびUndo履歴の保持を行う。 |  |  |  |
| BP-002 |  | 起動時に動作環境のブラウザ機能を評価し、ファイルの保存や編集がサポートされていないブラウザ（Blob非対応、非対応Safari等）において閲覧専用モードに制御する。 |  |  |  |
| BP-003 |  | お絵描き画面（KantanDrawer）における描画モード変更、線幅、枠線色、塗りつぶし色、フォント設定などの属性制御およびキャンバス要素への描画制御を行う。 |  |  |  |
| BP-004 |  | パース後のHTML要素から [!NOTE], [!TIP] 等で始まるブロック引用を検出し、GitHubスタイルのアラート要素（専用アイコン・CSSクラス）へ動的に変換・描画する。 |  |  |  |
| BP-005 |  | マークダウン内のシーケンス図テキストを解析し、Diagram、Actor、Signalなどのエンティティを生成してプレビュー画面上にシーケンス図を描画する。 |  |  |  |
| BP-006 |  | マークダウン内の記述からフローチャート定義テキストを構文解析し、Raphaelライブラリを介してSVG形式のフローチャートをレンダリングする。 |  |  |  |
| BP-007 |  | ユーザーによって入力されたマークダウンテキストを解析し、対応するHTML文字列に変換してプレビュー画面に反映する。 |  |  |  |
| BP-008 |  | プレビュー画面内にレンダリングされたコードブロック（code要素）に対してプログラミング言語を認識し、Highlight.jsを適用して構文強調（シンタックスハイライト）を行う。 |  |  |  |
| BP-009 |  | アプリケーションのバージョン比較を行い、必要に応じてアップデートダイアログを表示する。既存のマークダウン、CSS、添付ファイル（ベース64データ、トリミング情報、レイヤーコンテンツ）を引き継いだ状態でHTML全体の再構築・書き換えを行う。 |  |  |  |
| BP-010 |  | Gruntfileを利用してソースコード・スタイルシートのコピー、圧縮（cssmin, uglify）、置換（replace）、インライン化（inline）を実行し、用途に応じた複数エディション（dev, lite, std, full）の単一HTMLファイルをビルド生成する。 |  |  |  |
