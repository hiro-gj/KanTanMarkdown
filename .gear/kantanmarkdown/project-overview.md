# プロジェクト概要

## 概要
KanTanMarkdownは、単一のHTMLファイル（シングルHTML）内で完結して動作するスタンドアロン型のMarkdownエディタおよびプレビューアプロジェクトです。サーバーサイドのバックエンドに依存せず、ブラウザ上で直接ドキュメントの編集・プレビュー・画像添付・お絵描き・保存が可能な軽量かつ可搬性に優れた構造を持っています。

機能面では、テキスト編集機能（タブ入力やインデント操作など）に加えて、Markdownのパース処理、コードブロックのシンタックスハイライト、ダイアグラム（フローチャートおよびシーケンス図）の自動レンダリング、GitHubスタイルのアラート表示（[!NOTE]や[!TIP]など）、さらにHTML5 Canvasを活用した簡易お絵描き機能（kantanDrawer）が組み込まれています。

プロジェクトの構築と配布にはGruntを使用した自動化ビルドパイプラインが採用されています。複数のJavaScriptおよびCSSモジュールを圧縮・インライン化することで、単一の配布用HTML（Dev/Lite/Std/Fullなどのエディション）や更新スクリプトを生成する仕組みが整えられています。
