# 機能要件一覧

| id | functionName | description | relatedRequirement | priority |
| --- | --- | --- | --- | --- |
| FR-001 | マークダウンエディタ編集機能 | マークダウンエディタ画面において、Tabキー押下によるタブ挿入またはスペースへのタブ展開、Shift+Tabキー押下による複数行のアウトデント処理、およびUndo履歴の保存を行う機能。 | BR-001 | 高 |
| FR-002 | 閲覧専用モード判定・制御機能 | ブラウザの対応状況（Blob利用不可や非対応Safariなど）をチェックし、編集不可と判断された場合に警告メッセージを表示してツールバーの操作ボタンを無効化し、閲覧専用モードへ切り替える機能。 | BR-002 | 高 |
| FR-003 | お絵描き（ドロワー）描画機能 | お絵描き画面（KantanDrawer）において、描画モードの切り替え、枠線の太さ（borderWidth）や色（borderColor）、塗りつぶし色（fillColor）、フォント（font）の変更操作およびキャンバスへの描画を制御する機能。 | BR-003 | 中 |
| FR-004 | GitHubアラート変換機能 | プレビュー画面にて、解析されたマークダウン要素のうち [!NOTE] や [!TIP] 等で始まるブロック引用を検出し、専用のアイコン・スタイルを適用したGitHubアラートへ変換・描画する機能。 | BR-004 | 中 |
| FR-005 | シーケンス図パース・描画機能 | マークダウン内のテキストからDiagram、Actor、Signalなどのエンティティ情報を解析し、プレビュー画面上にシーケンス図を生成・描画する機能。 | BR-005 | 中 |
| FR-006 | フローチャートパース・描画機能 | マークダウン内の記述からフローチャート定義をパースし、Raphaelライブラリ等を介してSVGフローチャートを描画する機能。 | BR-006 | 中 |
| FR-007 | マークダウンレンダリング機能 | 入力されたマークダウンテキストをHTML形式に変換（マークダウンパース）し、プレビュー画面へリアルタイムに反映・表示する機能。 | BR-007 | 高 |
| FR-008 | コード構文ハイライト機能 | プレビュー画面内のコードブロックに対して言語を識別し、シンタックスハイライト（Highlight.js）を適用して整形表示する機能。 | BR-008 | 低 |
| FR-009 | バージョンアップデート・データ引き継ぎ機能 | アプリケーションのバージョン更新時にアップデートダイアログを表示し、既存のマークダウン、CSS、添付ファイル（ベース64データ、トリミング情報、レイヤーコンテンツ）を引き継いでHTMLを書き換える機能。 | BR-009 | 高 |
| FR-010 | マルチエディションビルド・パッケージング機能 | Gruntfileを通じてソースコードやCSS・JSの圧縮（cssmin, uglify）およびインライン化を行い、複数のエディション（dev, lite, std, full）に応じた単一HTMLファイルを生成するバッチビルド機能。 | BR-010 | 中 |
