# 画面UI定義書

## 画面と実DOM

| id | 初期値 | 挙動 |
| --- | --- | --- |

| setting-expand-tab | false | 選択なしTabの空白展開。幅4の次のタブ位置まで1〜4個、全角は幅2として計算 |

## キー操作
- 選択なしTab（Shift併用も同じ分岐）：タブ/空白挿入。Shift+Tabだけで単一行をアウトデントする仕様ではない。
- 選択ありTab：設定にかかわらず行頭へタブ挿入。選択ありShift+Tab：行頭から最大4スペースまたはタブ相当を削除。
- Ctrl/Cmd+Z、Ctrl/Cmd+Y、Ctrl/Cmd+Shift+Z：Undo/Redo。
- Ctrl/Cmd+S：保存。Ctrl/Cmd+Shift+S：書出し。F5 / Ctrl/Cmd+R：再読込ではなく手動プレビュー。
- F1：外部記法ヘルプ。F2：見出し同期。Alt+←/→：編集プレビュー表示/非表示。Alt+↓/↑：添付一覧表示/非表示。

## 表示と出力の制約
目次の位置ハイライトはpreviewerのscrollイベントが起点。閲覧モードではページ側がスクロールするため同等動作は保証しない。図はsequence / flowクラス要素が対象であり、標準フェンスから自動的に該当クラスへ変換する保証はない。
印刷CSSは `@page { size: A4 portrait; margin: 10mm; }` を指定し、目次を本文前に並べ全リンクのoverflow制限を解除する。ツールバー、添付領域（#attach）、設定、編集ペイン、リサイズハンドル、画面外計測iframe（`#kantan-print-measure-frame`）、改ページオーバーレイ（`#kantan-page-break-overlay`, `.page-break-indicator`）を非表示に指定する。

閲覧時の幅は最大300mmで、ビューポートと目次領域に応じて縮小する。最小高さ424mmを保ち、内容に応じて伸長する。`--page-aspect-ratio` は参照値であり、高さを拘束する `aspect-ratio` 指定ではない。改ページ目安はChromeの採用印刷条件（A4縦 210×297mm、余白上下左右10mm、倍率100%、ヘッダー/フッターOFF、背景ON、有効本文領域190×277mm）を前提に画面外iframeで独立計測し、ブロック・サブ項目・Range行位置から画面座標へ対応付ける。任意のブラウザ・印刷設定・HTML/CSSへの完全一致は保証せず、未準備・対象外条件では目安を非表示とし実印刷を妨げない。

設定パネル表示時にはバージョン取得とキャッシュ再取得も行う。処理はバックグラウンドで実行し、ページ再読込や原稿の置換は行わない。
