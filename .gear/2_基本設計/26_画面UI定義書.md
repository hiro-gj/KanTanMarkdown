# 画面UI定義書

## 画面と実DOM
すべて同一HTML上の表示切替。サーバーURLや別ページへの遷移ではない。起動時は閲覧モード。設定パネルを閉じても元の編集/閲覧状態を保持する。

| 画面ID | DOM | 入出力・操作 |
| --- | --- | --- |
| SCR-001 | editorTabWrapper / editor / cssEditor | markdownTabとcssTabでtextareaを切替。CSS変更は未保存扱いとなり次のdoPreviewで反映 |
| SCR-001 | toolbar-toggle / toolbar | メニュー開閉。閉じると編集モードなら閲覧モードへ。開くだけでは編集開始しない |
| SCR-001 | btn-toggle-mode | 編集/閲覧。ESCは設定パネルが開いていればパネルだけ閉じる |
| SCR-001 | btn-editor-zoom-in / btn-editor-zoom-reset | 編集モード時のみ表示。編集画面（editor/cssEditor）のズーム倍率を段階的に拡大（0.67→1→1.2→1.4→1.6→1.8→2） / 初期値（0.67）にリセット |
| SCR-001 | attachButton / paste-area / fileList | ファイル選択、bodyへのドロップ、paste-areaへの画像ペースト。エディタへの直接画像ペースト機能ではない |
| SCR-001 | fileList li | ↑↓で並替、fileNameのblurで改名、Insert Tag、Edit、Download、削除。Editは画像のみ有効 |
| SCR-001 | resize-handle | マウス・タッチ移動で幅20〜80%。CSS変数--editor-widthと設定値に保存 |
| SCR-001 | btn-save / btn-export | 編集可能HTML保存 / 閲覧用HTML書出し |
| SCR-002 | previewer / previewerStyle | marked生成HTMLとカスタムCSS。閲覧モード時はA4縦比率（300mm×424mm）、編集モード時は67%ズームかつeditorと双方向スクロール同期。sequence・flowクラスを図描画対象とする |
| SCR-002 | toc / .toc-body | h1〜h6を目次リンク化。見出しなしは「見出しがありません」。既存idを使い、なければheading-iを付与 |
| SCR-002 | btn-toggle-toc / btn-dark-mode | 目次表示状態 / body.dark切替。LocalStorageに保存 |
| SCR-003 | drawArea / canvasWrapper | 添付画像のEditから起動。baseCanvas=元画像、mainCanvas=確定描画、workCanvas=作業中描画 |
| SCR-003 | .mode button | Rectangle / Letter / Eraser / Trim。自由描画ペンはない |
| SCR-003 | .borderWidth / .scale | 値はdiv表示、±ボタンで変更。数値入力フィールドではない |
| SCR-003 | borderColor / fillColor / font | テキスト入力、色パレット、透明色。専用の厳密なカラー入力検証はない |
| SCR-003 | undoButton / redoButton / resetButton | 描画コマンド履歴、Resetは確認付きで元に戻せない |
| SCR-003 | saveButton / cancelButton | レイヤーPNG・trimInfoをコールバックに渡す / 破棄して復帰 |
| SCR-004 | importDialog | HTML取込と更新で共用。importDialogMessageは説明、importDialogAttach・Markdown・Cssはチェックボックス、OK/Cancelで確定 |
| SCR-004 | kantanVersion / kantanEdition | hidden要素。ユーザーが選ぶバージョン欄・エディションselectではない |
| SCR-005 | settings-panel | fixed、top/left 50%、translate(-50%,-50%)。hidden属性で開閉。背景操作を遮断する専用オーバーレイはない |

## 設定項目
| id | 初期値 | 挙動 |
| --- | --- | --- |
| setting-auto-sync | true | editorのchange/keyup後300ms待機してdoPreview |
| setting-expand-tab | false | 選択なしTabの空白展開。幅4の次のタブ位置まで1〜4個、全角は幅2として計算 |
| setting-auto-close-tag | false | kantanEditorの閉じタグ入力補助 |
| setting-insert-img-tag | false | 添付時の画像タグ挿入 |
| setting-require-trailing-spaces | false | marked.breaksを反転設定。trueなら通常改行は強制改行扱いにしない |

## キー操作
- 選択なしTab（Shift併用も同じ分岐）：タブ/空白挿入。Shift+Tabだけで単一行をアウトデントする仕様ではない。
- 選択ありTab：設定にかかわらず行頭へタブ挿入。選択ありShift+Tab：行頭から最大4スペースまたはタブ相当を削除。
- Ctrl/Cmd+Z、Ctrl/Cmd+Y、Ctrl/Cmd+Shift+Z：Undo/Redo。
- Ctrl/Cmd+S：保存。Ctrl/Cmd+Shift+S：書出し。F5 / Ctrl/Cmd+R：再読込ではなく手動プレビュー。
- F1：外部記法ヘルプ。F2：見出し同期。Alt+←/→：編集プレビュー表示/非表示。Alt+↓/↑：添付一覧表示/非表示。

## 表示と出力の制約
目次の位置ハイライトはpreviewerのscrollイベントが起点。閲覧モードではページ側がスクロールするため同等動作は保証しない。図はsequence / flowクラス要素が対象であり、標準フェンスから自動的に該当クラスへ変換する保証はない。
印刷CSSは目次を本文前に並べ全リンクのoverflow制限を解除する。添付非表示セレクタは実DOMのattachではなくattach-sectionであるため、編集モードからの印刷時に不要UIが完全に隠れるとは断定しない。
