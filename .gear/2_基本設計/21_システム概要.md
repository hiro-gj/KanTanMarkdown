# システム概要

## 調査基準
確認日：2026-11-01。基準：e5b2aee（アプリ本体 v2.20261101.01）。対象は src/ と Gruntfile.js を正とする本体。dist/ は配布物、ktm-new.html は別管理の入口、spinoff_pj_fork/ は移植元の別実装であり、本体仕様と混同しない。

## 実行構成
バックエンド、DB、HTTPルーティングを持たないブラウザ内アプリケーション。HTMLにCSS・JavaScript・原稿・添付ファイルを内包して保存する。起動時は原稿が空でも閲覧モードとなる。

| ソース | 責務 |
| --- | --- |
| src/ktm.html | ツールバー、添付一覧、Markdown/CSSタブ、プレビュー、目次、設定、取込ダイアログ |
| src/js/kantanMarkdown.js | DOMイベント、300ms待機後の描画、添付解決、保存/書出し/取込、目次、テーマ、幅調整 |
| src/js/kantanEditor.js | Tab、選択行のインデント、オートインデント、閉じタグ補助、Undo/Redo |
| src/js/kantanDrawer.js・src/kantanDrawer.html | 添付画像の矩形・文字・消しゴム・トリミング編集 |
| src/js/github-alerts.js | 5種類のGitHub Alerts変換、連続アラートの分割 |
| src/js/marked.min.js | Markdown解析。sanitizeは既定false、full/dev時はMermaidフェンスをdiv.mermaidへ変換 |
| src/js/highlight.min.js | markedのhighlightコールバックで構文強調（Mermaidコードブロックは除外保護） |
| src/js/js-sequence-diagrams.min.js・flowchart.min.js | sequence / flowクラスを持つ要素からSVG生成 |
| src/js/mermaid.min.js | full/devエディション用。GitHub準拠Mermaidフェンスから各種ダイアグラムSVG生成 |
| src/css/kantan.css・previewer.css・drawer.css・hljs.css | UI、本文、描画画面、コードのスタイル |
| src/kantanUpdate.js | 更新確認、既存データ退避、HTML・script再構成、選択データ復元 |

## 保持と通信の境界
- 原稿とCSSはtextarea、添付はfileList配下のscript[type="text/template"]に保持。原稿の自動バックアップはない。
- LocalStorageはcom.tatesuke.ktm.接頭辞の設定値のみ。読書き例外は捕捉して既定値に戻す。
- 内蔵機能はサーバー保存を要求しない。ただし外部画像・リンク・CSS URL、ヘルプ、新規作成、更新操作は通信し得る。通信や漏洩が原理的にないとは保証しない。
- 更新ボタンは http://tatesuke.github.io/KanTanMarkdown/kantanUpdate.js をscriptとして読み込む。HTTPSページではMixed Content制約を受け得る。フォーク先へ自動追従する実装ではない。
- 任意HTMLとカスタムCSSを許可し、プレビュー全体のサニタイズを有効化していない。信頼できない文書を安全に開ける保証はない。保存時の「<」エスケープはtextareaの構造保護であり、XSS対策とは別。

## ビルド・CI/CD仕様
Grunt 1.6.2系、依存はpackage.jsonのdevDependencies。Node v24+向けutil.isRegExpポリフィルをGruntfile先頭に置く。対応保証・処理時間は別途実測する。

| タスク | 機能・生成物 |
| --- | --- |
| build-dev | 圧縮なし、全ライブラリ内包、dist/ktm-dev.html |
| build-lite | CSS/主要JS圧縮、highlight・図ライブラリ・Mermaid除去、dist/ktm-lite.html |
| build-std | CSS/主要JS圧縮、highlightあり、図ライブラリ・Mermaid除去、dist/ktm-std.html |
| build-full | CSS/主要JS圧縮、全ライブラリ内包（Mermaid v9.4.3含む）、dist/ktm-full.html |
| build-updateJs | 全機能HTMLを文字列化しdist/kantanUpdate.jsへ埋込み（Mermaid含む） |
| update-new-sizes | dist/配下の実ファイルサイズを取得しktm-new.htmlの容量表記を自動同期 |
| build | 上記5タスクおよびupdate-new-sizesを順次実行 |
| default | src/**監視。変更時build-devとbuild-updateJs |

各ビルドはdist/tempを消去・再作成する。ktm-new.htmlの容量表記はビルド時に自動同期される。KaTeXは本体に未導入（Mermaidはfull/devに内包）。

### GitHub Actions (v7) および デプロイ構成
GitHub公式アクション最新メジャー（`actions/checkout@v7`, `actions/setup-node@v7`, `actions/configure-pages@v6`, `actions/upload-pages-artifact@v5`, `actions/deploy-pages@v5`）を採用。

- **CI テスト (`.github/workflows/test.yml`)**:
  - トリガー: `master` / `main` への push、pull_request（`paths-ignore` により `README.md`, `.gear/**`, `dist/preview/**` 等の機能に直接関係ないファイル変更時は発火除外）、および手動実行（`workflow_dispatch`）。
  - 内容: リポジトリのチェックアウト、Node.js 24 セットアップ、依存パッケージ導入、`grunt build` による生成物検証、`npm test`（`.tests/run-tests.js`）による全自動テストスイート実行。
- **GitHub Pages デプロイ (`.github/workflows/deploy-pages.yml`)**:
  - トリガー: GitHub Release 公開（`release: published`）、`master` ブランチへの push（`paths` フィルタにより `src/**`, `Gruntfile.js`, `package.json`, `ktm-new.html`, `.github/workflows/deploy-pages.yml` の機能関連更新時のみ発火）、および手動実行（`workflow_dispatch`）。
  - 特徴:
    - **リリース公開時（`release: published` / `workflow_dispatch`）**: リリースタグ名を `src/kantanVersion.txt` に同期して `grunt build` で `dist/` 直下（および `dist/preview/`）を再生成し、`ktm-new.html` のファイルサイズ表記を自動同期した上で、GitHub Pages（`dist/ktm-{lite,std,full}.html`）およびリポジトリ `master` ブランチの `dist/`・`ktm-new.html` へ公開。
    - **`master` マージ時（`push`）**: 最新ソースからビルドした成果物を `dist/preview/` サブフォルダへ配置し、`dist/` 直下のファイルおよび `ktm-new.html` は最新リリース版（`LATEST_TAG`）から復元保護した上で、GitHub Pages（`dist/preview/ktm-{lite,std,full}.html`）およびリポジトリ `master` ブランチの `dist/preview/` へ公開（リリース公開中の `dist/` 直下サイトおよび `ktm-new.html` には影響しない）。


## 既知の制約
setViewOnlyは警告とツールバーボタン無効化のみで認可機構ではない。Safari判定はUAにsafariがありchromeがない場合で、現行APIの能力判定ではない。exportHTMLは描画DOMの抽出で、Blob画像のData URL化、添付ストアの移送、ダークテーマや本体と同等の印刷CSS移送は行わない。生成HTMLの可搬性は検証が必要。
