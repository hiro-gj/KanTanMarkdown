# ER図

## 適用範囲
RDBを使用しないため、物理ER図は定義しない。以下に保存HTML内の包含関係、表示データへの参照、および端末設定の読出し関係を示す。

```mermaid
flowchart TD
  HTML[保存対象HTML] --> MD[textarea editor: Markdown]
  HTML --> CSS[textarea cssEditor: CSS]
  HTML --> META[hidden: kantanVersion / kantanEdition]
  HTML --> LIST[ul fileList]
  LIST --> LI[li: 添付1件]
  LI --> DATA[script: title=ファイル名 / id=attach-名前 / Data URL]
  LI --> LAYER[script.layerContent: PNG Data URL]
  LI --> TRIM[script.trimInfo: x y w h のJSON]
  MD --> PREVIEW[再生成プレビューDOM]

  PREVIEW --> TOC[目次リンク: data-targetで見出しid参照]
  STORAGE[localStorage: 設定キーと文字列値] -. 起動時復元 .-> HTML
```

添付名は追加時に重複を検出し _2 等を付加する。リネーム時は空名・重複名を拒否するが、本文内のattach:参照を自動書換えする処理はない。KantanDrawerインスタンスは画面で共有され、添付ごとのDB行ではない。Diagram/Actor/Signalはライブラリ内の一時解析オブジェクトであり、永続化テーブルではない。
