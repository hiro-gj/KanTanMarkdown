# 業務要件一覧

文書の作成・閲覧・共有に関する業務上の目的を定義する。動作条件と制約は非機能要件・設計書に定義する。

| ID | 分類 | 目的 |
| --- | --- | --- |
| BR-001 | 文書編集 | Markdown/CSSを構造化入力・履歴操作で効率的に編集する |
| BR-002 | 画像注釈 | 添付画像への矩形・文字・消去・トリミングを提供する |
| BR-003 | 図表 | テキストからシーケンス図・フローチャート・Mermaid図を表示し、図の例外を個別に扱う |
| BR-004 | 可読性 | Markdown・GitHub Alerts・構文強調で内容を読みやすくする |
| BR-005 | データ移行 | HTML取込と版更新で選択した原稿・CSS・添付を移送する |
| BR-006 | 環境対応 | 保存非対応と判定した環境に警告しツールバーを無効化する |
| BR-007 | 閲覧支援 | 目次と見出し同期で文書内の移動を支援する |
| BR-008 | 操作・表示 | メニュー、テーマ、幅調整、設定、印刷レイアウトを提供する |
| BR-009 | 保存・共有 | 編集可能HTML保存、閲覧用HTML書出し、添付の管理を行う |
| BR-010 | 配布 | 用途別4版と更新scriptをNode.jsビルドスクリプトとesbuildで生成する |
