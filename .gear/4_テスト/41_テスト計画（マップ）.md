## 実行条件・安全性
- 更新試験は隔離環境の既知スクリプトで行い、通常の回帰で本家HTTPの更新を適用しない。
- 不信HTML・外部URL試験は機密データなしの隔離環境のみ。
- 手動試験はブラウザ名/版、OS、エディション、file/HTTP起動、文書量を記録。
- 今回の文書更新検証と、アプリの全テスト実行完了は区別する。実施記録は本書末尾に追記する。

## CI 自動テストスイートの導入（`.tests/`）
GitHub Actions CI（`test.yml`）およびローカル開発環境での自動回帰検証を目的として、軽量なテスト支援ツール群を `.tests/` 配下に新設。

| スクリプト | 検証観点・対象 | 実行方式 |
| --- | --- | --- |
| `.tests/syntax-check.js` | 全JavaScriptソース（`Gruntfile.js`, `src/js/*.js`, `src/kantanUpdate.js`）の構文妥当性検証 | Node.js `vm.Script` |
| `.tests/alerts-parser.test.js` | GitHub Alerts 5種変換、タイトル・SVG付与、連続アラート分割、通常引用維持、冪等性 | 軽量DOMモック |
| `.tests/editor-logic.test.js` | Tab挿入、スペース展開、複数行インデント/アウトデント、オートインデント、閉じタグ補完、Undo/Redo | 軽量DOMスタブ |
| `.tests/build-integrity.test.js` | `dist/` 直下および `dist/preview/` サブフォルダ配下の各エディション（dev/lite/std/full/updateJs）・`ktm-new.html` の存在、容量範囲、リンク整合性、ライセンス表記、A4レイアウト・2画面ズーム・拡大/戻すボタン・双方向スクロール同期、および GitHub Actions ワークフロー（`deploy-pages.yml` / `test.yml`）のトリガー・公開先保護設定の検証 | Node.js fs / stat |
