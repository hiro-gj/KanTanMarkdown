## 実行条件
- ブラウザ名・版、OS、エディション、file/HTTP/HTTPS起動、文書量を記録する。
- 更新適用はバックアップを用意し、隔離環境の管理下スクリプトを使用する。
- 不信HTML・外部URLの試験には機密データを使用しない。
- 長文、長大ブロック、遅延画像、非同期Mermaid、狭幅、目次開閉、再描画、印刷、書出しを組み合わせる。画面改ページ目安と印刷の改ページは区別する。

## 自動テスト
リポジトリルートで `npm test` を実行する。`.tests/run-tests.js` は以下の7スイートを子プロセスで順次実行し、いずれかが失敗すると非0で終了する。

| スクリプト | 検証範囲 | 方法・制約 |
| --- | --- | --- |
| syntax-check.js | scripts、src、src/js/modulesのJavaScript構文 | vm.Script。インライン用プレースホルダーは検査用に置換 |
| alerts-parser.test.js | Alertsの定義・5種変換・分割・通常引用・冪等性 | 軽量DOMモック |
| qiita-note.test.js | Qiita Note構文3種、省略時のinfoフォールバック、未知サブタイプ、空本文、連続Note、前後の通常段落保持、CRLF、3個以上コロン、コードフェンス保護、リッチMarkdown、二重登録防止、スタンドアロンAPI | 同梱markedおよびQiitaMarkerプラグイン単体・変換テスト |
| editor-logic.test.js | Tab、複数行インデント、改行補助、閉じタグ、Undo/Redo | 軽量DOMスタブ |
| mermaid-parser.test.js | Mermaidフェンス変換、非搭載時表示、ハイライト除外、描画失敗、非同期図とキャッシュ | markedと描画処理のスタブ。実ブラウザのSVGレイアウトは対象外 |
| modules-unit.test.js | 分割モジュール、4段階保存処理、イベント重複登録防止、旧ブラウザ分岐排除、Pages公開ステージング、リリース昇格（無改変コピー・版番号／マニフェスト／ソースSHA／再ビルド照合・master worktree 同期・プレビュー不変） | Node.js上での単体検証 |
| build-integrity.test.js | 配布物、バージョン・リンク・容量、ライブラリ構成、CSS/JS指定、Qiita Note/サードパーティライセンス収録、ワークフロー設定（検証コミット固定・アーティファクト範囲・worktree 同期） | ファイル存在・サイズ・文字列検査。実レイアウト・印刷位置・GitHub Actions 実行は対象外 |

## ビルドと手動確認
依存導入はリポジトリルートで `npm ci`（または `npm install`）、ビルドは `npm run build` とする。通常ビルドは `dist/preview/` の4版と更新JS、および `ktm-new.html` のプレビュー容量表記を更新し、`dist/` 直下の本番成果物を保護する。リリース時は `npm run promote:release` により確認済みの `dist/preview/` 成果物（または `--artifact-dir` で指定した検証済み成果物）を版番号・マニフェスト・SHA-256 照合のうえ無改変で `dist/` 直下へ昇格し、本番容量表記のみを更新する。

自動テストの合格は手動ケースの合格を意味しない。ブラウザでの操作、保存ファイルの再開、画像可搬性、遅延描画、実印刷/PDF、外部通信は対象ケースに従って確認する。
