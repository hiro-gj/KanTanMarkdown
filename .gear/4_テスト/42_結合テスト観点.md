# 結合テスト観点

DOMイベント・変換ライブラリ・データ保持・出力処理間の受渡しを確認する。実施記録は手順・期待結果の定義と分けて管理する。

| 観点ID | 対象 / 要件 | 確認内容・制約 |
| --- | --- | --- |
| ITV-001 | 編集・履歴 / FR-001 | 選択なしTabは設定に応じてタブまたは次の幅4のタブ位置まで1〜4空白を挿入する。選択なしShift+Tabも挿入となる。選択ありTabは各行にタブを挿入し、Shift+Tabは行頭の最大4スペースまたはタブ相当を削除する。Undo/Redoで編集前後を復元する。 |
| ITV-002 | 環境制御 / FR-002 | Blob生成失敗またはUAがsafariを含みchromeを含まない条件で警告を表示し、#toolbar buttonをdisabledにする。textareaや他の操作経路を強制禁止する処理はない。 |
| ITV-003 | 画像編集 / FR-003 | SaveでPNGレイヤーと矩形JSONを添付DOMへ反映し、画像キャッシュを破棄してプレビューを更新する。Cancelは編集中の変更を反映しない。 |
| ITV-004 | Alerts / FR-004 | 対応する5種のマーカーを専用クラス・タイトル・SVGへ変換し、連続するアラートを分割する。通常引用を維持する。 |
| ITV-005 | 図 / FR-005, FR-006 | full/devではsequence/flowクラスの有効な定義をSVGへ変換する。解析・描画例外は原文とdiagram-errorで表示する。lite/stdでは図ライブラリを実行しない。標準フェンスはlang-sequence等となり、sequence/flowへの自動変換対象ではない。 |
| ITV-006 | 同期と構文強調 / FR-007, FR-008 | 自動同期ONでは最後のchange/keyupから300ms待機して描画を開始し、OFFでは入力のみで更新しない。F5等で即時描画する。std/full/devではコード構文強調を適用し、liteでは適用しない。インラインコード（code, tt）はコンテナ幅に応じて折り返され、上下パディング（2px 5px）によりアンダースコア（_）と外枠が重ならない。添付動画への `attach:` リンクはダウンロードリンクを維持したまま直下に操作パネル付き `<video>` を生成・解決し、直下に同一添付の明示 `<video>` がある場合は重複生成せず再利用する。CSS変更は次のプレビューに反映する。 |
| ITV-007 | 更新引継ぎ / FR-009 | 確認承認後に選択した原稿・CSS・添付のみを引き継ぎ、エディションを保持する。同版文字列の場合は追加確認し、取消時は再構築しない。更新scriptの取得先は起動パスの/dist/preview/有無で分岐し、時刻クエリを付加する。 |
| ITV-008 | ビルド / FR-010 | devは全機能を非圧縮で、fullは全機能を主要JS/CSS圧縮で生成する。liteは構文強調と図ライブラリを除外し、stdは構文強調のみ含む。更新JSを生成し、既存ktm-new.htmlの容量表記を実サイズで更新する。 |
| ITV-009 | 目次 / FR-011 | h1〜h6のリンクを再生成し、既存idまたはheading-iを参照する。最小見出しレベルを基準に字下げする。見出しなしではメッセージを表示する。クリックで移動し、previewerのscrollでactiveを更新する。ページscrollの監視は行わない。 |
| ITV-010 | 見出し同期 / FR-012 | 編集モードの見出しクリックで原稿の対応行を選択し、F2でカーソル位置に対応するプレビュー見出しへ移動する。対応付けは独自の原稿見出し解析に従う。 |
| ITV-011 | UI状態 / FR-013 | メニューを閉じると閲覧へ移行する。閲覧枠は最大幅300mm・最小高さ424mmで内容に応じて伸長する。改ページ目安はChrome採用印刷条件（有効本文領域190×277mm）を画面外計測iframe（`#kantan-print-measure-frame`）で独立計測して境界モデルを算出し、通常フローを変えない絶対配置オーバーレイ（`#kantan-page-break-overlay` 内の `.page-break-indicator`）へ描画する。反復描画や画面幅・モード・テーマ・表示スケール・ページズーム変更で同一印刷条件の境界モデルが変わらず、本文要素の位置も変化しない。編集時は初期67%ズーム、拡大/戻す、比率スクロール同期、幅20〜80%の調整が動作する。 |
| ITV-012 | 保存再開 / FR-014 | 編集可能HTMLに原稿・CSS・添付を含み、計測iframe・改ページオーバーレイ・仮属性を除外し、再開時に復元する。原稿内の<はtextarea内でエスケープする。保存要求時にsaved=trueとなり、ダウンロード完了・取消の結果は監視しない。 |
| ITV-013 | 閲覧用書出し / FR-014 | 編集UIを含まないHTMLを生成し、目次ON時だけ目次を含める。書出し時のテーマ変数とカスタムCSSを含める。Blob URLのData URL化、添付ストア、本体印刷CSS、改ページ表示用CSSと再計算処理、非同期描画完了待機は含めない。 |
| ITV-014 | 添付管理 / FR-015 | ファイル選択・ドロップ・paste-areaへの画像貼付で添付を追加する。同名は_2等で回避し、空名・重複名への改名を拒否する。Insert Tagは画像で `<img>`（CSSタブ時は `url(...)`）、動画で `<a><br>\n<video controls preload="metadata" playsinline>`、一般ファイルで `<a>` を挿入する。削除・改名時は画像および動画のBlob URLキャッシュを破棄する。改名時に本文・CSSのattach:参照は変更しない。 |
| ITV-015 | HTML取込 / FR-015 | 選択した原稿は区切りなしで末尾連結し、CSSは上書きし、添付は追加する。取込取消時は元のHTMLを通常添付する。 |
| ITV-016 | 設定と永続化 / FR-016 | 6設定（自動プレビュー、タブ展開、閉じタグ自動挿入、画像添付時タグ挿入、改行末尾スペース2個必須、改ページインジゲータを表示する `#setting-show-page-break`）とUI状態をLocalStorageから復元し、読書き例外を捕捉する。`#setting-show-page-break` の初期値はチェックなし（OFF）であり、ON時に改ページインジケーターを表示しOFF時に即座に消去する。本文・添付は自動保存しない。設定表示と起動後100msのタイマーでバージョン取得を行い、成功時は表示とhidden値を更新する。HTTP/HTTPS起動時は元URLも再取得するが画面再読込は行わない。ESCは設定を閉じ、編集/閲覧状態を保持する。 |
| ITV-017 | 印刷 / FR-017, NFR-009 | `@page { size: A4 portrait; margin: 10mm; }` を指定し、画面用改ページオーバーレイ・計測iframe・編集UIを印刷CSSで非表示に指定する。目次ONでは全見出しを本文前に配置する。本文の幅・最小高さ・枠・影・余白の二重加算を解除しzoomを1にする。プレビュー内の `<video>` は非表示にし、キャプチャ済み印刷用サムネイル画像（`img.kantan-video-print-thumb`）を表示する。Mermaidの対象4図種はzoom:0.5、Qiita Noteは分割禁止（`break-inside: avoid`）となる。横向き等の対象外条件でも実印刷を妨げない。 |
| ITV-018 | 性能 / NFR-001, NFR-002 | 起動時間、入力後の待機時間と描画時間、メモリ使用量を文書量・図数・添付数・環境別に記録できる。300msは待機設定値であり処理時間の上限ではない。 |
| ITV-019 | 通信と信頼境界 / NFR-003, NFR-005 | サーバー保存APIは使用しない。起動・設定表示のfetchと明示更新のscript取得、および文書内の外部参照を通信として区別する。markedのsanitize=false、MermaidのsecurityLevel=looseを確認する。任意HTML/CSSを隔離する機構はない。 |
| ITV-020 | 障害・保持 / NFR-004, NFR-007, NFR-010 | 未保存状態で離脱警告を要求し、LocalStorage例外と図の解析・描画例外を捕捉する。再開時に保持される原稿・添付は保存HTMLの内容となり、未保存変更の自動復旧は行わない。 |
| ITV-021 | Mermaid描画 / FR-018 | full/devでMermaidフェンスまたはmermaidクラス要素をSVG化する。mindmap等はrenderAsyncを使用し、テーマと原文をキーにSVGをキャッシュする。ダーク時はdarkテーマを指定する。解析・描画失敗はmermaid-errorで表示し、lite/stdではMermaidフェンスを通常コードとして表示する。印刷CSSの対象4図種はzoom:0.5となる。 |
