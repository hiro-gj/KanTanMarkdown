# システムテスト観点

本書は現行実装の再調査に基づき、従来の自動生成ケースを整理・再採番した現行版。旧ケース番号との一対一対応はない。仕様と不一致の目標、未実装UI、架空DBを前提にしたケースは置換した。全ケースの実行状態は未実施（テスト設計）であり、実施時は環境・版・日付・証跡・結果を別途記録する。

| 観点ID | 対象 / 要件 | 確認内容・制約 |
| --- | --- | --- |
| STV-001 | 編集・履歴 / FR-001 | 次のタブ位置まで1〜4空白、またはタブ。選択ありTabはタブ挿入、選択なしShift+Tabは挿入扱い |
| STV-002 | 環境制御 / FR-002 | 警告とtoolbar button無効化。直接API等まで禁止するセキュリティ機構ではない |
| STV-003 | 画像編集 / FR-003 | SaveでPNGレイヤー/矩形JSONが反映、Cancelは破棄。自由描画ペンや数値入力欄を前提にしない |
| STV-004 | Alerts / FR-004 | 対応マーカーのみ専用クラス・タイトル・SVGへ変換し、連続アラートを分割 |
| STV-005 | 図 / FR-005, FR-006 | 有効図はSVG、不正図は原文とdiagram-errorで後続処理継続。標準コードフェンスのクラスは別途確認 |
| STV-006 | 同期と構文強調 / FR-007, FR-008 | 有効時は最後のイベントから300ms後に開始、無効時は自動更新しない。300ms以内完了の保証ではない |
| STV-007 | 更新引継ぎ / FR-009 | 選択項目のみ復元。editionは保持。同版は確認。実外部更新はHTTP先/安全性を確認してから実施 |
| STV-008 | ビルド / FR-010 | dev全機能非圧縮、liteはhighlight/図なし、stdはhighlightのみ、fullは全機能。ktm-newは生成対象外 |
| STV-009 | 目次 / FR-011 | リンク再生成、階層字下げ、見出しなしメッセージ、移動とactive更新。ページscrollは制約として分離 |
| STV-010 | 見出し同期 / FR-012 | 原稿該当行またはプレビュー見出しに移動。複雑なHTML見出しは独自解析とのずれを記録 |
| STV-011 | UI状態 / FR-013 | メニューを閉じると閲覧へ、閲覧時A4縦比率（300mm×424mm）、編集時2画面67%ズーム・拡大/戻すボタン・双方向スクロール同期、幅は20〜80%。LocalStorage設定復元と実表示を比較 |
| STV-012 | 保存再開 / FR-014 | 編集可能HTMLとして復元し、原稿内<をtextareaへエスケープ。ダウンロード取消でもsaved扱いになる制約を記録 |
| STV-013 | 閲覧用書出し / FR-014 | 編集UIなし、目次はON時のみ。本体Blob URLの残存・画像欠落・ダーク/印刷CSS差は既知制約として記録 |
| STV-014 | 添付管理 / FR-015 | 同名は_2等で回避。空/重複rename拒否。本文参照の自動renameなし。editor直接pasteを仕様にしない |
| STV-015 | HTML取込 / FR-015 | 原稿は区切りなし末尾連結、CSS上書き、添付追加。取消は通常HTML添付になる |
| STV-016 | 設定と永続化 / FR-016 | 設定値復元、例外時は既定値で継続。原稿/添付の自動保存はしない。ESCは開いた設定だけ閉じる |
| STV-017 | 印刷 / FR-017, NFR-009 | 目次ONは本文前へ全見出し表示。実DOMと異なるattach-section指定や編集UI残存は不具合として記録 |
| STV-018 | 性能 / NFR-001, NFR-002 | 環境・サイズ・開始/完了時刻を記録。1秒や300msを達成済みとしない |
| STV-019 | 通信と信頼境界 / NFR-003, NFR-005 | サーバー保存APIはないが外部通信は可能。sanitize=falseを確認。不信文書の安全性を合格扱いしない |
| STV-020 | 障害・保持 / NFR-004, NFR-007, NFR-010 | 警告/例外捕捉の範囲を確認。未実装のバックアップや全操作禁止を期待しない |
| STV-021 | Mermaid描画 / FR-018 | full/devでGitHub準拠```mermaidフェンスから各種ダイアグラムSVG生成、ダークモード連動、構文エラー時非クラッシュ、lite/stdで安全なコード表示維持 |

根拠：src/ktm.html、src/js/kantanMarkdown.js、kantanEditor.js、kantanDrawer.js、github-alerts.js、src/kantanUpdate.js、src/css/kantan.css、Gruntfile.js。
